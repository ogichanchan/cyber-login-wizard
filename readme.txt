== Description ==
Cyber Login Wizard provides a unique, cyber-style login experience for your WordPress site. This PHP-only utility transforms your default WordPress login page into a sleek, console-like interface with green text on a dark background, embodying a "wizard" aesthetic. All CSS and JavaScript are embedded inline, adhering to a "no external files" rule, ensuring simplicity and efficiency.

Key features include:
*   **Distinctive Cyber Theme:** Overhauls the login page with a dark, tech-inspired design.
*   **Inline Assets:** All styling and scripting are self-contained within the plugin's single PHP file, reducing external requests.
*   **Customizable Welcome Message:** Set a personalized welcome message that appears with a dynamic typing effect.
*   **Enable/Disable Theme:** Easily activate or deactivate the cyber theme from the plugin's settings page in the WordPress admin.
*   **Custom Login Title:** Changes the browser tab title to "System Login - Cyber Console" when the theme is active.
*   **Dynamic Footer:** Adds a dynamically generated copyright message to the login page.

Designed for those who seek a minimalist, efficient, and visually unique login solution for their WordPress installation.

This plugin is open source. Report bugs at: https://github.com/ogichanchan/cyber-login-wizard
