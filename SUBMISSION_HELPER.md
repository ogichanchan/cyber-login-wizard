1.  **Plugin Name:** Cyber Login Wizard
2.  **Short Description:** A unique PHP-only WordPress utility that transforms the default login page into a dynamic, cyber-style interface. It acts as a wizard, focused on simplicity and efficiency, providing a themed and engaging login experience.
3.  **Detailed Description:**
    Cyber Login Wizard reimagines your WordPress login page with a distinctive cyber-style theme. This plugin focuses on delivering a unique visual experience without relying on external CSS or JavaScript files; all styling and scripts are embedded inline within a single PHP file for maximum simplicity and efficiency.

    **Key Features:**
    *   **Cyber-Themed Login Page:** Overhauls the default WordPress login screen with a dark, grid-pattern background, neon green text, and cyberpunk-inspired styling for form fields, buttons, and links.
    *   **Custom Welcome Message:** Configure a personalized welcome message from the plugin settings, which will be prominently displayed at the top of the login page.
    *   **Typing Effect:** The custom welcome message appears with a subtle, engaging typewriter animation, enhancing the "cyber" feel.
    *   **Custom Login Header:** Replaces the standard WordPress logo with your site's name, dynamically styled to match the cyber theme, and links back to your main site.
    *   **Custom Browser Title:** Changes the browser tab title of the login page to "System Login - Cyber Console" for a consistent theme.
    *   **Dynamic Footer Message:** Automatically adds a copyright message to the login page footer, including the current year and site name.
    *   **Admin Settings Page:** Easily manage plugin options from a dedicated settings page under 'Settings > Cyber Login Wizard'. Here you can:
        *   Toggle the "Enable Cyber Theme" to activate or deactivate the custom styling.
        *   Set your desired "Welcome Message" via a simple textarea field.
    *   **Clean Activation/Deactivation:** Upon activation, the plugin automatically enables the cyber theme and sets a default welcome message. Upon deactivation, it cleanly removes all its stored options from your database.

    This plugin is ideal for users looking to add a futuristic, tech-savvy touch to their WordPress login process with minimal overhead.
